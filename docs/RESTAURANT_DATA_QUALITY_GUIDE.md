# CIA Smart Menu — требования к данным ресторана

Для максимально точного автоматического анализа меню ресторану важно правильно вести ингредиенты и техкарты в Poster.

CIA Smart Menu использует названия ингредиентов, тип позиции, единицы измерения, количество в техкарте и состав полуфабрикатов для определения:

- калорийности;
- белков, жиров и углеводов;
- аллергенов;
- переводов;
- пригодности блюда под выбранные ограничения гостя.

Чем точнее исходные данные в Poster, тем выше точность результата.

## 1. Используйте конкретные названия ингредиентов

Избегайте слишком общих или внутренних названий, которые не описывают продукт.

| Нежелательно | Лучше |
| --- | --- |
| Мясо | Свинина, корейка, сырая |
| Говядина | Говядина, поясничная часть |
| Рыба | Лосось, филе, сырой |
| Сыр | Моцарелла |
| Молоко | Молоко 3.2% |
| Масло | Масло подсолнечное рафинированное |
| Орехи | Миндаль сырой |
| Соус | Соус Цезарь, собственного производства |
| Сливки | Сливки 20% |
| Шоколад | Шоколад тёмный 70% |

Если имеет значение жирность, вид обработки, часть туши, сорт или состояние продукта — укажите это в названии.

## 2. Не используйте только внутренние сокращения

Названия вроде `мясо 1`, `сыр А`, `соус Z`, `заготовка 5` или только код поставщика могут быть понятны сотрудникам ресторана, но недостаточны для автоматического анализа.

Если внутреннее обозначение необходимо, добавьте понятное название продукта, например:

- `Соус Z — томатный острый`;
- `Мясо 1 — свиная корейка`;
- `Сыр А — моцарелла`.

## 3. Полуфабрикаты должны иметь собственные техкарты

Для ресторанных заготовок нельзя надёжно использовать среднее значение из интернета.

Примеры:

- фарш для хинкали;
- фарш для долмы;
- кавурма;
- паштет;
- маринад;
- фирменный соус;
- крем;
- начинка;
- тесто.

Такие позиции должны быть заведены как отдельные заготовки/полуфабрикаты с реальным составом и количеством ингредиентов.

CIA Smart Menu должен рассчитывать их пищевую ценность по этой техкарте, а затем использовать результат внутри готовых блюд.

## 4. Указывайте правильные количества и единицы измерения

Для расчёта калорийности особенно важны реальные граммы или миллилитры ингредиента в порции.

Рекомендуется использовать:

- `г` — для продуктов по массе;
- `мл` — для жидкостей, когда рецептура ведётся по объёму;
- штуки — только когда вес одной штуки известен или стабилен.

Например, запись `1 шт. яйцо` без известного веса менее точна для автоматического расчёта, чем техкарта, в которой известен фактический вес продукта.

## 5. Указывайте состояние продукта, если оно влияет на пищевую ценность

Разные состояния одного продукта могут значительно отличаться по калорийности на 100 г.

Примеры:

- рис сухой / рис варёный;
- мясо сырое / мясо приготовленное;
- картофель сырой / картофель фри;
- орехи сырые / жареные;
- овощи свежие / маринованные;
- молочный продукт с разной жирностью.

## 6. Для брендовых продуктов указывайте бренд и точный вид

Если ресторан использует конкретный продукт с собственной пищевой ценностью, лучше сохранять точное название.

Например:

- `Red Bull Original`;
- `Nutella`;
- `Monin Vanilla Syrup`;
- конкретный соус или напиток производителя.

Для таких товаров CIA Smart Menu может использовать данные производителя или этикетки вместо усреднённого аналога.

## 7. Аллергены также зависят от точности названия и состава

Название `соус`, `крем`, `хлеб`, `шоколад` или `фарш` само по себе не всегда позволяет определить все аллергены.

Для собственных заготовок должны быть заполнены ингредиенты техкарты. Это особенно важно для:

- молока и молочных продуктов;
- яиц;
- орехов;
- арахиса;
- глютена;
- сои;
- рыбы;
- ракообразных и моллюсков;
- горчицы;
- кунжута и других аллергенов.

## Рекомендация перед запуском CIA Smart Menu

Перед первым полным анализом ресторану рекомендуется проверить:

1. Названия основных ингредиентов.
2. Жирность и вид продукта там, где это важно.
3. Единицы измерения и реальные количества в техкартах.
4. Состав всех собственных полуфабрикатов и соусов.
5. Отсутствие дублирующихся ингредиентов с разными непонятными названиями.

После этого CIA Smart Menu сможет автоматически обработать большую часть меню значительно точнее.

## Важно

CIA Smart Menu не должен придумывать точное значение, когда исходных данных недостаточно.

Если часть техкарты не распознана или требует подтверждения, система должна показывать блюдо как `частично рассчитано` и, при наличии известной части, отображать минимальное подтверждённое значение (`≥`).

Точность Smart Menu напрямую зависит от качества исходных данных ресторана в Poster.
